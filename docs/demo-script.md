# Demo script (about 3 minutes)

**Before recording (not on camera):** follow `docs/demo-setup.md`. Have two rooms ready from the same template: one in **Telegram**, one in **Discord**. Make new agent keys, reset the Figma and Canva files, close old pull requests. Open: the landing page, the dashboard, the Telegram group, the Discord channel, the Figma file and the Canva design.

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | Landing page | "Brand drift is everywhere: an old blue in code, the old font in Figma, a Canva poster nobody updated. Markpath fixes it with a team of agents in a Switch room." |
| 0:15 | Dashboard: Overview, Issues | "Markpath knows the brand rules. These are the issues it found, grouped, with old and new values." |
| 0:30 | **Telegram** group | Type `@mp-director fix the issues`. "Plain words. The Director plans; the Design agent reads the real Figma file and Canva design." |
| 0:55 | Telegram: Director's approval message | "Nothing changes until a person approves this exact change." Reply `@mp-director approve`. |
| 1:15 | Figma and Canva updating | "The Design agent edits through the official Figma and Canva connectors. Colours, type and corners only." |
| 1:35 | GitHub pull request | "Code arrives as a pull request. Never merged for you, main branch untouched." |
| 1:50 | Telegram: Brand QA report | "A separate QA agent re-reads everything. The agent that made the change never marks its own work." |
| 2:05 | **Discord** channel | Paste a Figma link: `@mp-director is this on brand? <link>`. "Same agents, another chat app. Reviews are read-only." |
| 2:25 | Dashboard: Reviews, Activity | "Every check, approval and change is on record." |
| 2:40 | Integrations: setup steps | "Setup takes a few minutes: rules from your guideline or website, GitHub, Figma, Canva, then your chat. Connecting a chat app takes about 3 minutes; one-click install is next." |
| 2:55 | Close | "Switch is the control room. Without it there is no team, no approvals in chat, no independent QA." |

**Honesty notes to say once:** Canva can't change fonts. Slack and Teams are coming soon. The agents run in Switch on my machine today.
