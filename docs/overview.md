# Markpath overview

Markpath is a brand operations platform that turns an approved brand specification into auditable detection, coordination, correction, and verification across design and code resources.

The MVP uses an authenticated five-page dashboard for configuration, evidence, and approvals; SQLite for durable operational records; deterministic local fixtures for GitHub-style and Figma-style work; and Switch Rooms for human-agent and agent-agent collaboration. Switch server reachability may be checked locally, but a successful health response is not a room connection: Markpath requires a verified addressed agent reply before showing Switch as connected.
